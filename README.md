# Yashas HK — Portfolio

A responsive React + Vite portfolio based on my resume.

## Run locally

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
```

Deploy to Vercel with framework preset **Vite**, build command `npm run build`, and output directory `dist`.

## Before publishing

- Replace the LinkedIn search URL in `src.jsx` with your actual LinkedIn profile URL.
- Add verified project repository/live links if desired; the resume did not include project URLs.
- The included `resume.pdf` is the resume used to create this site.
